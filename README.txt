INTER MUSIC LIBRARY - PROVA FULL-STACK

REQUISITO
Installa Node.js LTS da https://nodejs.org

WINDOWS
Fai doppio clic su AVVIA_WINDOWS.bat

MAC
Fai clic destro su AVVIA_MAC.command > Apri

MANUALE
1. Apri il terminale nella cartella
2. npm install
3. npm start
4. Apri http://localhost:3000

PROVA
Il link Goya è già inserito. Premi Analizza.
